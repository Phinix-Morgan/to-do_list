# To-Do List

A simple and responsive To-Do List web application built using HTML, CSS, JavaScript, and Bootstrap. The application allows users to create, manage, and delete tasks while automatically saving them in the browser using Local Storage.

[https://phinix-morgan.github.io/to-do_list/](https://phinix-morgan.github.io/to-do_list/)

## Features

- Add new tasks with a title and description.
- Delete completed or unwanted tasks.
- Automatically saves tasks using Local Storage.
- Tasks persist even after refreshing the browser.
- Clean and responsive user interface built with Bootstrap.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap
- Browser Local Storage API

## Project Structure

- `index.html` – Main application interface.
- `style.css` – Custom styling for the application.
- `app.js` – Handles task management, Local Storage operations, and dynamic table updates.
- `css/` – Local Bootstrap CSS files.
- `js/` – Local Bootstrap JavaScript files.

## How It Works

- Enter a task title and description.
- Click **Add To List** to save the task.
- Tasks are stored in the browser's Local Storage.
- Every saved task is displayed in the task table.
- Delete tasks individually using the **Delete** button.
- Saved tasks remain available even after closing or refreshing the browser.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Phinix-Morgan/to-do_list.git
cd to-do_list
```

### Run the project

Open `index.html` in your preferred web browser.

No installation or additional dependencies are required.
